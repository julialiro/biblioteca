Sistema de Gerenciamento de Biblioteca

Este projeto foi desenvolvido em Python para gerenciar livros de uma biblioteca, permitindo cadastrar, emprestar, devolver, listar, buscar e ordenar livros.

1-Cadastro dos livros
O usuário informa título, autor, ano e código. O livro começa com o status disponível.

2-Empréstimo e devolução
O sistema permite emprestar e devolver livros, alterando automaticamente o status.

3-Listagem e busca
É possível visualizar todos os livros e pesquisar pelo título ou autor.

4-Ordenação
Os livros podem ser organizados por título, autor ou ano.

5-Salvamento
Os dados são salvos no arquivo livros.csv e carregados novamente ao iniciar o programa.

6-Menu
O sistema utiliza if/elif/else e while para manter o menu funcionando até a opção Sair.

Arquivos

livros.csv — dados dos livros.

README.md — documentação do projeto.
